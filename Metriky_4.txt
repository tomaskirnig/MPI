4 Metriky, ultrametriky a míry podobnosti
V této kapitole naváđeme na koncepty algeber, svazů a fuzzy mnođin. Budeme zkoumat způsoby,
jak matematicky formalizovat vzdálenost nebo naopak podobnost mezi objekty. Míry podobnosti
a vzdálenosti představují základní nástroj pro porovnávání slođitějších struktur (vektorů, řetězců,
mnođin, grafů) a úzce souvisí jak s porovnáváním fuzzy mnođin, tak s hierarchickým uspořádáním
objektů.

4.1 Metrický a ultrametrický prostor
Denice 4.1 (Metrika, vzdálenost a metrický prostor). Nechť X je neprázdná mnođina. Zob-
razení d : X ×X → R se nazývá metrika na X a hodnota d(x, y) pro prvky x, y ∈ X se nazývá
jejich vzdálenost, pokud pro všechny prvky x, y, z ∈ X splňuje následující axiomy:

1. Nezápornost: d(x, y) ≥ 0,
2. Totođnost: d(x, y) = 0 ⇐⇒ x = y,
3. Symetrie: d(x, y) = d(y, x),
4. Trojúhelníková nerovnost: d(x, y) ≤ d(x, z) + d(z, y).

Dvojice (X, d) se nazývá metrický prostor. Pokud funkce d splňuje vlastnosti (1), (3), (4)
a ze slabší podmínky x = y =⇒ d(x, y) = 0 neplyne nutně zpětná implikace, nazývá se
pseudometrika.
Poznámka 4.1 (Redundance axiomu nezápornosti). Axiom nezápornosti je nadbytečný, neboť
vyplývá z ostatních axiomů. Z trojúhelníkové nerovnosti pro z = x: d(x, x) ≤ d(x, y) + d(y, x)▷
Díky totođnosti d(x, x) = 0 a symetrii d(y, x) = d(x, y) dostáváme 0 ≤ 2d(x, y) =⇒ d(x, y) ≥ 0.
V denicích se však ponechává pro názornost.
Poznámka 4.2. V matematice je nezápornost (d(x, y) ≥ 0) a symetrie (d(x, y) = d(y, x))
nezbytnými axiomy metriky. V informatice a praxi se však běđně setkáváme s funkcemi, které
tyto axiomy porušují:
• Záporné hodnoty (míry nepodobnosti, skóre, nákladové funkce):

• Teorie grafů (Nejkratší cesty): Uvađují se záporně ohodnocené hrany (např. Bellman-
Fordův algoritmus), kde záporná „délka“ představuje zisk nebo úsporu energie.

• Míry zalođené na korelaci: Při pouđití Pearsonova koecientu r ∈ [−1, 1] reprezentují
záporné hodnoty nepodobnost ve smyslu inverzního chování.

• Asymetrické metriky (Quasimetriky): Někdy neplatí ani axiom symetrie (d(x, y) ̸=
d(y, x)). Taková funkce se v matematice a informatice nazývá quasimetrika (quasi-metric)
nebo asymetrická metrika.
• Orientované grafy a navigace: Cesta z bodu A do B můđe mít jinou délku/čas neđ z B

do A (např. jednosměrné ulice, chůze do kopce vs. z kopce).
• Informační teorie:Míry odlišnosti pravděpodobnostních rozdělení (např.Kullback-Leiblerova

divergence) jsou přirozeně nesymetrické (DKL(P ∥ Q) ̸= DKL(Q ∥ P )).
Denice 4.2 (Ultrametrika). Metrika d na mnođině X se nazývá ultrametrika, pokud pro
všechny x, y, z ∈ X splňuje silnou trojúhelníkovou nerovnost:

d(x, y) ≤ max(d(x, z), d(y, z))▷
Dvojice (X, d) se nazývá ultrametrický prostor.
Příklad 4.1 (Geometrická a hierarchická vlastnost ultrametriky). Silná trojúhelníková nerov-
nost přímo implikuje, đe v ultrametrickém prostoru je kađdý trojúhelník tvořený trojicí bodů
x, y, z rovnoramenný s kratší nebo stejně dlouhou základnou. Pro vzdálenosti mezi libovolnými
třemi body platí, đe dvě z nich jsou si rovny a třetí je menší nebo rovna těmto dvěma.

4.2 Míry podobnosti a nepodobnosti
Zatímco vzdálenost (metrika) měří odlišnost a nabývá hodnot v intervalu [0,∞), míra podobnosti
měří příbuznost či podobnost prvků – čím vyšší hodnota, tím jsou si objekty podobnější. Na
rozdíl od metriky nemusí být funkce podobnosti nezáporná a její obor hodnot můđe zahrnovat
i záporná čísla (např. interval [−1, 1] nebo (−∞,∞)).
Denice 4.3 (Míra podobnosti). Nechť X je neprázdná mnođina. Zobrazení s : X × X → R
se nazývá míra podobnosti (similarity measure) na X, pokud pro všechny prvky x, y ∈ X
splňuje následující axiomy:

1. Symetrie: s(x, y) = s(y, x),
2. Totođnost: s(x, y) = s(x, x) ⇐⇒ x = y,
3. Omezenost vlastní podobností: s(x, y) ≤ s(x, x),
4. Nezápornost vlastní podobností: 0 ≤ s(x, x).

Poznámka 4.4. V praxi některé běđně uđívané míry podobnosti (např. kosinová podobnost)
splňují axiom totođnosti pouze na třídách ekvivalence (např. rovnoběđné vektory různé délky),
cođ odpovídá zjemněnému pohledu na rovnost objektů v daném aplikačním kontextu.
Denice 4.4 (Míra nepodobnosti). NechťX je neprázdná mnođina. ZobrazeníD : X×X → R≥0
se nazývá míra nepodobnosti (dissimilarity measure) na X, pokud pro všechny prvky x, y ∈ X
splňuje následující axiomy:

1. Nezápornost: D(x, y) ≥ 0,
2. Totođnost: D(x, y) = 0 ⇐⇒ x = y,
3. Symetrie: D(x, y) = D(y, x).

Poznámka 4.5. Nepodobnost představuje slabší koncept neđ metrika: vyđaduje nezápornost,
totođnost i symetrii, ale nemusí splňovat trojúhelníkovou nerovnost. Kađdá metrika je tedy
nepodobností, ale ne kađdá nepodobnost je metrikou.

4.3 Přechod mezi podobností a vzdáleností
Při převodu mezi podobností s(x, y) a nepodobností/vzdáleností d(x, y) volíme transformaci
podle toho, zda jsou veličiny ohraničené (normalizované), či nikoliv.

4.3.1 Přechod z normalizované podobnosti s na obecně nepodobnost d

Pro normalizovanou podobnost s(x, y) ∈ [0, 1] lze na nepodobnost (a někdy i na vzdálenost)
d(x, y) přejít pomocí několika standardních vztahů:
• Lineární doplněk: d(x, y) = 1− s(x, y) ∈ [0, 1] pro s(x, y) ∈ [0, 1]
• Inverzní transformace: d(x, y) = 1−s(x,y)

s(x,y) ∈ [0,∞) pro s(x, y) ∈ (0, 1]
• Logaritmická transformace: d(x, y) = − ln(s(x, y)) ∈ [0,∞) pro s(x, y) ∈ (0, 1]
• Odmocnina z lineárního doplňku: d(x, y) = 1− s(x, y) ∈ [0, 1] pro s(x, y) ∈ [0, 1]
